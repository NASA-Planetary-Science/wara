# GUI

wara ships a full PyQt5-based GUI covering all analysis features.

## Launching

```bash
wara -o
```

## Features

- Spectrum smoothing, rebinning, and plotting
- Interactive peak finding and fitting
- Isotope identification with built-in nuclear databases
- Energy and efficiency calibration
- FWHM vs. energy characterisation
- Time analysis from LYNX list-mode data
- PIXIE API data visualization for Associated Particle Imaging (API)
